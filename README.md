# The Drawer That Was Locked for Forty Years

An entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) bounty **"Make the AI judge feel curious"**.

`main.py` writes one short text (~276 characters) to `/output/entry.txt`: a locked desk drawer, a key found yesterday, a note in a dead grandmother's handwriting saying "Not yet", and a photograph of a house the narrator has never seen — with their own name on the back, in ink that is still wet. A concrete unanswered thread the judge cannot resolve from the text alone.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13 standard library only; the output is byte-identical across runs.
